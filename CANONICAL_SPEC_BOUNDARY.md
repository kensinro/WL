# Canonical Specification Boundary

The empirical implementation represented by this public reference package is associated with the frozen internal Writing Layer specification state used for the study.

The complete authoritative specification is **not required to be publicly disclosed** in this Minimum Public Proof Layer.

The public package instead preserves:

- the identity of the frozen study state;
- a bounded implementation sufficient for public inspection;
- a frozen manuscript-facing evidence record;
- tests, integrity checks, and release metadata.

A later internal Writing Layer version may extend or refine the system but must not retrospectively rewrite the frozen empirical record.

`public proof package != full internal specification`

`later WL version != retrospective replacement of the frozen study state`
