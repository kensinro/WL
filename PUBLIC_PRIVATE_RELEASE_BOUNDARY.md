# Public / Controlled-Reviewer / Private Boundary

## Tier 1 — Public Proof Layer

This repository.

May contain:

- bounded reference validators;
- frozen public evidence summaries;
- tests and controlled fixtures;
- reproducibility instructions;
- manifest and release metadata;
- citation metadata;
- CI configuration.

## Tier 2 — Controlled Reviewer Verification

May be prepared separately if an editor or reviewer requires deeper verification and Human authorization permits it.

It is not automatically redistributable.

## Tier 3 — Private Development Record

Not part of this repository.

May include:

- complete Writing Layer specifications;
- private rule libraries;
- implementation-sensitive modules;
- historical development archives;
- internal Human-Gate records;
- future/prospective capabilities;
- commercializable know-how.

Public reproducibility does not require automatic disclosure of Tier 3.
